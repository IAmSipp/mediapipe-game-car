# ปรับแต่งเกม

| ไฟล์ | ใช้ปรับอะไร |
|---|---|
| `control_settings.py` | เลือกท่าควบคุมแบบสำเร็จรูป |
| `hand_controls.py` | เขียนกฎควบคุมเอง เมื่อ USE_PRESET = False |
| `game_settings.py` | ความเร็ว คะแนน ขนาด และสี |

**เริ่มง่าย ๆ** เปิด `control_settings.py` แล้วเลือกโหมดและสองท่า เช่น:

```python
USE_PRESET = True  # False = ใช้ hand_controls.py
LEFT_ACTION = "ชูสองนิ้วซ้าย"
RIGHT_ACTION = "ชูสองนิ้วขวา"
```

ชื่อท่าอื่นคัดลอกได้จากรายการในไฟล์เดียวกัน เพิ่ม `SENSITIVITY` เพื่อให้ทำท่าผ่านง่ายขึ้น และปรับ `HOLD_SECONDS` เพื่อกำหนดเวลาค้างท่า

**อยากเขียนเอง** ตั้ง `USE_PRESET = False` แล้วแก้ `hand_controls.py` ชื่อท่า ความไว และเวลาค้างของสำเร็จรูปจะไม่ถูกใช้ สลับกลับเป็น `True` เพื่อใช้สำเร็จรูปได้เลย

**แก้เสร็จ → บันทึก → ปิดและเปิดเกมใหม่**
