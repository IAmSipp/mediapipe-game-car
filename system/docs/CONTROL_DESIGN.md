# ข้อเสนอ: ให้ผู้เรียนเลือกท่าควบคุมโดยไม่ต้องเขียนโค้ด

สถานะอัปเดต: ตอนนี้ทำไฟล์ `setting/control_settings.py` ให้เลือกสำเร็จรูปหรือเขียนเองด้วย USE_PRESET = True/False แล้ว พร้อม Hand/Pose สำหรับมือ แขน ลำตัว และเอียงศีรษะ ดูการใช้งานจริงใน `setting/README.md` ส่วนหน้าตั้งค่าด้วยเมาส์ ตัวสร้างกฎ การตั้งท่ากลาง และ Face/Gesture Recognizer ที่อธิบายต่อไปนี้ยังเป็นข้อเสนอสำหรับพัฒนาต่อ

## รูปแบบที่แนะนำสำหรับเวิร์กชอป

ให้มีหน้า **ตั้งค่าการควบคุม** ใน Pygame ก่อนเริ่มเกม ผู้เรียนเลือกด้วยเมาส์และเห็นผลบนกล้องทันที โดยเริ่มจากท่าสำเร็จรูป แล้วค่อยมีตัวสร้างกฎสำหรับคนที่อยากทดลองต่อ

1. เลือกส่วนที่ใช้: **มือ / แขนและลำตัว / ใบหน้า**
2. เลือกท่าสั่งไปซ้ายและท่าสั่งไปขวาจากเมนูพร้อมรูปตัวอย่าง เลือกข้างซ้าย/ขวาจริงของผู้เล่นได้
3. ปรับแถบ **ทำท่าง่าย–ยาก** และ **ต้องค้างท่านานเท่าไร** เริ่มทดลองที่ 0.2 วินาที แล้วปรับกับเครื่องจริง
4. กด **ตั้งท่ากลาง** เพื่อเก็บท่าปกติสั้น ๆ และกด **ลองควบคุม** เพื่อดูตัวอย่างรถโดยไม่มีสิ่งกีดขวาง
5. กด **บันทึกชุดควบคุม** ตั้งชื่อ เช่น “ชูสองนิ้ว” หรือ “ยกแขน” แล้วนำกลับมาใช้ได้ ไม่ต้องปิดโปรแกรมเพื่อทดลองค่าใหม่

ตัวอย่างที่ผู้เรียนเห็น:

```text
ส่วนที่ใช้            [แขนและลำตัว ▾]
ไปเลนซ้าย เมื่อ       [ข้อมือซ้าย] [อยู่เหนือ] [ไหล่ซ้าย]
ไปเลนขวา เมื่อ        [ข้อมือขวา] [อยู่เหนือ] [ไหล่ขวา]
ต้องค้างท่า            [0.2 วินาที]
เกิดพร้อมกัน          [อยู่เลนเดิม]

[ตั้งท่ากลาง]  [ลองควบคุม]  [บันทึก]
```

ชื่ออวัยวะควรเป็นภาษาไทย มีจุดที่เกี่ยวข้องสว่างบนภาพกล้องเมื่อเลือกเมนู ผู้เรียนไม่ต้องจำ landmark 15 หรือเขียน `if` แต่ยังเห็นว่ากฎใช้ข้อมูลส่วนไหน

## ทำท่าอื่นนอกจากกำมือ/แบมือได้อย่างไร

| รูปแบบ | สิ่งที่ให้ผู้เรียนเลือก | ส่วนที่ผู้สอนเตรียม |
|---|---|---|
| ท่ามือสำเร็จรูป | ชูนิ้วชี้, ชูสองนิ้ว, ยกนิ้วโป้ง, คว่ำนิ้วโป้ง, I love you รวมถึงกำมือและแบมือ | ใช้ MediaPipe Gesture Recognizer ซึ่งคืนชื่อท่า ข้างมือ และ landmarks |
| รูปแบบนิ้วเอง | เลือกแต่ละนิ้วเป็น **เหยียด / งอ / ไม่สนใจ** เช่น ชี้กับก้อยเหยียด | กฎจาก Hand Landmarker; กฎนิ้วโป้งต้องเตรียมแยกจากนิ้วอื่น |
| จีบนิ้ว/แตะนิ้ว | เลือก **ปลายนิ้วโป้งใกล้ปลายนิ้วชี้** แล้วปรับความใกล้ | คำนวณระยะของจุด 4 และ 8 เทียบขนาดฝ่ามือ เพื่อไม่ผูกกับระยะห่างจากกล้อง |
| ท่าที่เคลื่อนที่ | เช่น ปัดมือซ้าย/ขวา | เก็บตำแหน่งย้อนหลังและตรวจระยะในช่วงเวลาจริง ไม่ใช่ดูเฟรมเดียวหรือใช้จำนวนเฟรม |

Gesture Recognizer มีท่าที่เตรียมไว้ 7 ท่า: `Closed_Fist`, `Open_Palm`, `Pointing_Up`, `Thumb_Up`, `Thumb_Down`, `Victory`, `ILoveYou` ส่วน `None` คือไม่เข้ากลุ่มท่าที่รู้จัก จีบนิ้ว รูปแบบนิ้วที่ตั้งเอง และการปัดมือจึงต้องมีกฎเพิ่ม ไม่ใช่เลือกชื่อท่าแล้วโมเดลรู้จักทันที อ้างอิง [Gesture Recognizer ทางการ](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer?tab=Python)

ถ้าเลือกใช้ Gesture Recognizer ก็ใช้ landmarks ที่มันคืนมาสำหรับกฎจีบนิ้วร่วมด้วยได้ ไม่จำเป็นต้องเปิด Hand Landmarker ซ้ำอีกตัวในโหมดมือ

## ใช้อวัยวะส่วนอื่นได้อย่างไร

ตัวอย่างต่อไปนี้เป็นกฎที่เสนอให้ผู้สอนเตรียม ไม่ใช่ชื่อท่าที่โมเดลเหล่านี้จำแนกให้สำเร็จ:

| ส่วนที่ใช้ | ตัวอย่างสั่งซ้าย / ขวา | MediaPipe ที่ใช้ | สิ่งที่ต้องเตรียม |
|---|---|---|---|
| แขน | ยกข้อมือซ้ายเหนือไหล่ซ้าย / ยกข้อมือขวาเหนือไหล่ขวา | Pose Landmarker | กฎตำแหน่ง จุดซ้าย 15/11 และขวา 16/12 |
| ข้อศอก | งอแขนซ้าย / งอแขนขวา | Pose Landmarker | คำนวณมุมจากไหล่–ศอก–ข้อมือ และแถบตั้งช่วงมุม |
| ลำตัว | เอนซ้าย / เอนขวา | Pose Landmarker | วัดแนวไหล่เทียบสะโพกและท่ากลาง ไม่ใช้ตำแหน่งคนบนจออย่างเดียว |
| เข่าหรือเท้า | ยกเข่าซ้าย / ยกเข่าขวา | Pose Landmarker | เทียบกับท่ายืนกลาง ต้องจัดกล้องให้เห็นช่วงขา |
| ศีรษะ | เอียงศีรษะซ้าย / ขวา | Face Landmarker | คำนวณมุมเอียงจาก landmark/เมทริกซ์ใบหน้า เทียบกับท่ากลาง |
| ดวงตา | ขยิบตาซ้าย / ขยิบตาขวา | Face Landmarker | ใช้คะแนน blendshape ของการปิดตา พร้อมตรวจว่าอีกตายังเปิด และไม่สั่งเมื่อปิดพร้อมกัน |
| ปาก | อ้าปากเป็นคำสั่งหนึ่ง หรือใช้ร่วมกับอีกกฎ | Face Landmarker | เปิดผล blendshapes แล้วกำหนด threshold; จะสั่งสองทิศต้องมีอีกท่าหรืออีกเงื่อนไขให้แยกได้ |

[Pose Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker?tab=Python) ให้จุดร่างกาย 33 จุด รวมไหล่ ศอก ข้อมือ สะโพก เข่า ข้อเท้า และเท้า แต่ไม่ได้อ่านรายละเอียดนิ้วมือแทน Hand Landmarker ส่วน [Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker?tab=Python) ให้จุดใบหน้าและคะแนนการแสดงสีหน้า 52 ค่าเมื่อเปิด `output_face_blendshapes=True` จึงใช้เป็นข้อมูลสร้างกฎตา/ปากได้ คะแนนเหล่านี้ไม่ใช่ผลตัดสินว่าเป็นท่าควบคุมเกมสำเร็จรูป

หากภายหลังต้องใช้มือ ใบหน้า และท่าร่างกายพร้อมกัน ค่อยพิจารณา [Holistic Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/holistic_landmarker?tab=Python) หรือรวม task ที่จำเป็น สำหรับเวิร์กชอปแรกควรโหลดเฉพาะโมเดลของโหมดที่เลือก เพื่อลดเวลารอและภาระประมวลผล

## โครงสร้างข้อมูลสำหรับรุ่นที่มีหน้าตั้งค่า

แยกข้อมูลตัวเกมและข้อมูลควบคุมต่อไป:

- `setting/game_settings.py`: ความเร็ว คะแนน ขนาด สี และค่าเกม เหมือนที่ทำแล้วในรุ่นนี้
- `control_profiles.json`: ชุดกฎที่หน้าเมนูบันทึก ผู้เรียนไม่จำเป็นต้องเปิดแก้ JSON เอง
- ตัวอ่านกฎ: จับคู่ชื่อกฎกับฟังก์ชันที่ผู้สอนเตรียม เช่น **อยู่เหนือ**, **อยู่ใกล้**, **มุมอยู่ในช่วง**, **คะแนนสีหน้ามากกว่า** ไม่รันข้อความเป็น Python
- ส่วนตรวจจับ: เลือกโมเดลที่ต้องใช้ แล้วส่งข้อมูลมือ/ร่างกาย/ใบหน้าที่มีชื่อชัดเจนให้ตัวอ่านกฎ
- เกมยังรับเพียง `LEFT`, `RIGHT`, `None` จึงไม่ต้องแก้กติกาถนนเมื่อเปลี่ยนอวัยวะ

ตัวอย่างข้อมูลที่หน้าเมนูจะสร้างในรุ่นถัดไป (ยังไม่ได้เชื่อมกับเกมปัจจุบัน):

```json
{
  "name": "ยกแขน",
  "source": "pose",
  "left": {"rule": "wrist_above_shoulder", "side": "Left"},
  "right": {"rule": "wrist_above_shoulder", "side": "Right"},
  "hold_seconds": 0.2,
  "on_conflict": "HOLD"
}
```

ส่วน `setting/hand_controls.py` ปัจจุบันยังเหมาะกับผู้เรียนที่อยากก้าวต่อไปลองอ่าน/แก้ `if` หลังทดลองผ่านเมนูแล้ว จึงเก็บเป็นบทเรียนเขียนโค้ดเบื้องต้นได้

## สิ่งที่ต้องมีเพื่อให้ผู้เริ่มต้นลองแล้วเข้าใจ

- แสดงเงื่อนไขเป็นประโยค พร้อมไฟสถานะ **พบอวัยวะ / ท่าผ่าน / ยังไม่ผ่าน / คำสั่งที่จะส่ง** และไฮไลต์เฉพาะจุดที่ใช้
- วัดระยะเทียบขนาดมือหรือร่างกาย และมีปุ่มตั้งท่ากลาง เพื่อไม่ต้องตั้ง threshold ใหม่เพียงเพราะคนตัวเล็กหรืออยู่ไกลกล้อง
- ใช้เวลาจริงสำหรับระยะค้างท่า เริ่มต้นทดลองประมาณ 0.2 วินาที; แยกเกณฑ์เริ่มและหยุดเล็กน้อยเพื่อลดการสั่นบริเวณ threshold
- ถ้าไม่พบอวัยวะ/ความมั่นใจต่ำ ต้องล้างท่าที่ค้างและคืน `None` ทันที ถ้าผ่านทั้งคำสั่งซ้ายและขวาพร้อมกันให้คืน `None` ก่อนตัวกรองค้างท่า เพื่อไม่ส่งคำสั่งเดิมที่เพิ่งค้างผ่าน
- รองรับเลือกเลนด้วยท่าค้างเหมือนเกมปัจจุบัน ไม่บังคับให้ปล่อยแล้วทำใหม่ทุกครั้ง และรีเซ็ตตัวกรอง/ประวัติเมื่อเล่นใหม่หรือเปลี่ยนชุดควบคุม
- ยึดข้างจริงของผู้เล่น ภาพที่ส่งให้โมเดลไม่กลับกระจก แล้วค่อยกลับภาพและจุดตอนแสดงผล พร้อมให้ลองทีละข้างก่อนเริ่ม
- จับคู่กล้องกับกิจกรรม: หน้า/มือใช้ภาพใกล้ได้ ส่วนขาต้องเห็นช่วงขาและมีพื้นที่ขยับ หลีกเลี่ยงการตั้งท่าที่ผู้เล่นทำไม่ได้เป็นค่าเริ่มต้น

ลำดับพัฒนาที่แนะนำ: **เลือกท่าสำเร็จรูป → เมนูสร้างกฎจากชื่ออวัยวะ → ท่าเคลื่อนไหวตามเวลา → ฝึกตัวจำแนกท่าเฉพาะเมื่อกฎไม่เพียงพอ** โดยเริ่มรุ่นถัดไปด้วยชูนิ้วชี้/ชูสองนิ้ว, ยกแขนซ้าย–ขวา และเอียงศีรษะซ้าย–ขวา ซึ่งครอบคลุมทั้งมือ ร่างกาย และใบหน้าให้ผู้เรียนเลือกตามความถนัด
